**Not stale fixture, not chunk order — and both were ruled out by measurement.**
A fresh harvest (`h4`) reproduces the 2026-07-22 fixture at **0 of 884,736**, so

**The cause is concurrency, and one system property removes it.** `ChunkMap`
dispatches chunk status upgrades onto `Util.backgroundExecutor()`, sized
`availableProcessors() - 1`; features write one chunk out, so which chunk
decorates first is a race. Under `VANILLA_JVM_OPTS=-Dmax.bg.threads=1`: four
runs, six pairs, **all 0**. `docs/DETERMINISM.md` §37.
